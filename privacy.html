Privacy Policy

Last updated: October 3, 2026

1. Who operates this tool

Shorts Pipeline is a private tool operated by a single creator for their own accounts. Contact: siggi3925@gmail.com.

2. Data the tool uses

  • Google / YouTube: an OAuth refresh token for the operator's own YouTube channel. It is used to list public videos of configured source channels, upload videos to the operator's channel and change the privacy status of those uploads.
  • TikTok: an OAuth refresh token for the operator's own TikTok account (scopes user.info.basic and video.upload). It is used to identify the account and to send finished videos to its inbox as drafts.
  • Video processing: transcripts of source clips may be sent to a text analysis service (Anthropic Claude API) to choose an opening sentence.

The tool does not collect, store or process personal data of any other person, and it has no users other than the operator.

3. Storage and security

Tokens are stored as encrypted secrets in the operator's private GitHub repository and are only available to the automated job. A log of processed video IDs is kept in the same private repository. No data is sold or shared with third parties.

4. Google API Services

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Revoking access

Access can be revoked at any time in the Google account settings (myaccount.google.com/permissions) and in the TikTok app under Settings → Security → Manage app permissions. Stored tokens are deleted when the tool is no longer used.
